## 1. MILES: Modular Instruction Memory with Learnable Selection for Self-Improving LLM Reasoning

**基本信息**
- 作者: Ruilin Tong, Dong Gong
- 发布: 2026-07-08
- 会议/期刊: arXiv 2026 (preprint)
- 引用数: 0 📈 (刚发布)
- arXiv: [2607.06974](https://arxiv.org/abs/2607.06974)

**主要贡献**
针对 LLM 在连续解题中如何**积累可复用经验**的问题，指出现有记忆方案的两难：存整段完整解答泛化差，启发式检索又没有针对"选出来的记忆是否真能帮模型答对"做优化。提出 **MILES**：可动态扩展的 **step-wise 指令记忆** + **可学习的记忆选择机制**，让模型在自我改进中学会"该记什么、该取什么"。

**方法**
记忆被组织成**模块化单元**：每个单元将**子目标 (sub-goal) 嵌入**与对应**指令**配对存储，随解题过程逐步扩展。检索采用**两阶段**流程 —— 粗粒度阶段扩大候选记忆范围以收集监督信号；细粒度阶段用**训练好的 selection head** 对不确定样本精选记忆单元，选择器直接以最终正确性为优化目标，而非相似度启发式。

**实验**
在推理任务上取得与强基线相当或更优的准确率，同时改善了"记忆规模 vs 推理效率"的权衡；消融验证了可学习选择头相对启发式检索的增益，并展示了记忆库跨任务的**可迁移性**与鲁棒性。

**结论**
把经验记忆拆成子目标级模块、并用以正确性为目标的可学习选择器代替相似度检索，是让 LLM 实现自我改进推理的有效路径：记忆不在于存得多，而在于取得准。

## 2. MORES: Mobile Reasoning-as-a-Service via Distributed LLM Inference-Time Scaling

**基本信息**
- 作者: Guanchen Liu, Hongyang Du, Kaibin Huang
- 发布: 2026-07-09
- 会议/期刊: arXiv 2026 (preprint)
- 引用数: 0 📈 (刚发布)
- arXiv: [2607.08116](https://arxiv.org/abs/2607.08116)

**主要贡献**
首次把 **inference-time scaling（推理时扩展）**做成面向移动端的**服务范式**：边缘设备无需更大模型，通过无线网络按需调用"推理即服务" (Reasoning-as-a-Service)，将增强推理能力从模型规模问题转化为**分布式计算调度**问题。

**方法**
采用**隐式推理 (implicit reasoning)** 路线：将隐状态 (hidden-state) 的迭代更新在**边缘设备与边缘服务器之间切分**，设备侧与服务器侧协同完成潜空间推理。在此之上把"算多少、传多少、何时传"建模为**计算-通信联合调度**优化问题，用 **semantic Mixture-of-Experts 深度强化学习**算法求解，按语义特征路由到不同专家策略。

**实验**
在分布式推理服务场景下，所提 MoE-DRL 调度算法相对 **Soft Actor-Critic (SAC)** 基线取得约 **18% 的系统吞吐量提升**，验证了隐状态切分 + 语义感知调度在无线边缘环境中的有效性。

**结论**
推理时扩展不必被锁死在云端大模型里：通过潜空间推理的设备-服务器切分与语义化 DRL 调度，移动端也能以服务形式获得可扩展的 LLM 推理能力，为 6G 边缘智能提供了新的系统原语。

## 3. Detecting Answer-Driven Reasoning in LLM-Based Educational Tutors via Truncated Chain-of-Thought Auditing

**基本信息**
- 作者: Bonan Shen, Dingyan Shang, Youting Wang, Tao Ning
- 发布: 2026-07-06
- 会议/期刊: arXiv 2026 (preprint)
- 引用数: 0 📈 (刚发布)
- arXiv: [2607.04572](https://arxiv.org/abs/2607.04572)

**主要贡献**
揭示 LLM 辅导系统中的**"答案驱动推理"**风险：当模型能接触教师笔记、答案册、评分细则等私有信息时，看似循循善诱的步骤讲解可能只是**先知道答案再倒推的伪解释**。提出用**截断式 CoT 审计**作为轻量级过程级诊断，检测答案在讲解写完之前是否已"行为上可得"。

**方法**
采用 **TRACE (Truncated Reasoning AUC Evaluation)**：在生成讲解的不同前缀比例处截断，强制模型立即作答并与标准数值答案核对，度量"多早的 CoT 前缀就足以给出正确答案"。在 1000 道 GSM8K 测试题上对比三种配对辅导语境：仅题目、附正确答案册、附错误答案册。

**实验**
以 Qwen2.5-3B-Instruct 为对象：接触答案册使中位 TRACE AUC 从 **0.375 飙升至 0.900**；**997/1000** 的题目在讲解仅生成 10% 前缀时答案就已可得。在两种语境最终都答对的 746 道题上效应依然显著 —— 说明差异来自推理过程本质不同，而非答对与否。

**结论**
正确且格式规范的讲解 ≠ 从题目出发的真实推理。截断式 CoT 审计无需读取内部激活即可暴露答案泄漏式的伪推理，为教育场景 LLM 的过程可信度提供了实用审计工具。
